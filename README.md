# DW2-AA3
Uma rede de lojas possui unidades em 4 regiões do Brasil. Atualmente, o controle de vendas, comissões e metas dos vendedores é realizado por planilhas. Com o crescimento da rede, torna-se necessário desenvolver um sistema que armazene dados em banco relacional, automatize o cálculo de comissões e disponibilize relatórios de desempenho comercial.
